A FEW THINGS TO KNOW

开始之前

通用版和个人版有什么区别？

通用版是现成的 700 句情境练习，直接打开即可使用，也可添加到主屏幕。个人版用同一套语法话题骨架和学习框架，把例句改成你的真实经历，并生成原生 iPhone 应用与教材。更推荐个人版，因为你练的正是自己想说的话。

通用版怎么安装到 iPhone？

用 Safari 打开通用版，点击分享，选择“添加到主屏幕”；如有“作为网页 App 打开”选项，保持开启。先在线打开一次以缓存内容，之后可离线练习。Apple 操作说明 ↗

能直接下载一个所有人都能装的原生 IPA 吗？

目前公开入口提供主屏幕网页应用；原生版本提供开源工程，由自己的 Mac / Xcode 与 Apple 签名安装。当前未开放 App Store / TestFlight 分发，也不提供共享开发者证书。下载原生通用版工程 ↗。Apple 原生应用分发说明 ↗

个人经历会公开吗？需要额外的 API key 吗？

开源包只有通用资源与虚构示例。个人内容由你使用的 AI 在自己的项目中生成，是否上传给模型取决于你选择的 AI 环境。生成后的学习应用在本机保存进度，运行时不调用模型 API，也不需要另填 API key。请勿把自己的私人句库或原始材料直接提交到公开仓库。

适合雅思口语吗？能保证分数吗？

框架按 IELTS Speaking Part 1 / 2 / 3 的日常、叙事与观点话题组织，强调语法范围、准确性与自然表达。它是学习方法与训练材料，不是官方题库，也不保证分数。把例句换成自己的真实经历，练习变化和连贯回答，会更接近这个项目的初衷。
