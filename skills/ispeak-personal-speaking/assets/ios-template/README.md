# 句屿 · iSpeak 1.1

口语和语法，一次练一句。学完一个语法点后，解锁这一节的背诵。

- 学习顺序与原有课程保持不变，左滑或点下一句，随时接着上次继续。
- 在背诵页设置每日新学与复习目标，新句和到期旧句混合练，也可先复习。
- 只看中文开口，揭晓后自查：背错需要两次隔开的回忆；有点难更快回来；正确逐步拉长复习间隔；斩永久移出。
- 普通句卡尽量一屏显示，按钮固定在底部；长句与大字号保留必要的阅读空间。
- 可在每日计划中自选开启本地提醒。学习进度保存在这台设备。

升级会保留已学、已斩与旧版已完成记录，原进度文件会在转换前备份。使用同一应用身份覆盖安装，以保留原有数据。

<details><summary>构建与验证</summary>

用 Xcode 打开 `iSpeak.xcodeproj`，选择 iPhone 模拟器运行。核心规则执行 `scripts/test_core.sh`；界面测试使用独立进度文件，不会修改正常使用记录。真机安装需要连接手机和自己的 Apple 签名。
